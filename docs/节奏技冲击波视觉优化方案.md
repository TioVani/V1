# 节奏技冲击波视觉优化方案

## 目标

参考联连技冲击波的"环内半透明填充遮罩"效果，为节奏技的两种冲击波（点击冲击波 + 结算冲击波）增加同样的视觉层次感。

---

## 现状对比

### 联连技冲击波（LinkChainSystem.js L991-998）

```
绘制金色外环（ctx.arc + stroke）
  ↓
绘制环内半透明金色填充（ctx.arc + fill）
  - 颜色: rgba(255, 215, 0, 0.10~0.15)
  - 脉动: innerAlpha = 0.10 + 0.05 * sin(now / 120)
  - 半径: ringRadius * 0.85
```

### 节奏技点击冲击波（RhythmSkillSystem.js L719-740）**→ 当前无填充**

```
绘制青色外环（ctx.arc + stroke）
  - 颜色: rgba(0, 255, 255, alpha)
  ↓
绘制白色内环（ctx.arc + stroke）
  - 颜色: rgba(255, 255, 255, alpha)
  - 半径: waveRadius * 0.85
```

### 节奏技结算冲击波（RhythmSkillSystem.js L506-527）**→ 当前无填充**

```
绘制各色外环（ctx.arc + stroke）
  - 颜色: 根据连击数决定（青/金/紫）
  ↓
【无任何环内填充】
```

---

## 优化方案

### 一、点击冲击波（每次成功点击的扩散波）

**位置**：`RhythmSkillSystem.js` 第731行 `ctx.stroke()` 之后，`waveAlphaInner` 白环之前

**新增逻辑**：

```
// 青色半透明遮罩：环内区域淡青色填充
var waveMaskAlpha = (1 - waveProgress) * 0.12;  // 透明度从 0.12 → 0 线性衰减
ctx.fillStyle = 'rgba(0, 255, 255, ' + waveMaskAlpha.toFixed(3) + ')';
ctx.beginPath();
ctx.arc(rs.x, rs.y, waveRadius * 0.85, 0, Math.PI * 2);
ctx.fill();
```

**参数取值说明**：
| 参数 | 值 | 理由 |
|------|-----|------|
| 颜色 | `rgba(0, 255, 255, ...)` | 节奏技主题色为青色 `#00FFFF`，与联连技金色同理 |
| 峰值透明度 | `0.12` | 联连技峰值 0.15，节奏技稍淡避免喧宾夺主 |
| 衰减曲线 | `(1 - waveProgress) * 0.12` | 线性衰减，与外环同步 |
| 填充半径 | `waveRadius * 0.85` | 与联连技一致，填充到环半径的 85% |

**不推荐加脉动**：点击冲击波持续时间仅 400ms，脉动周期（约 750ms）无意义。

---

### 二、结算冲击波（连击结算时的全屏扩散波）

**位置**：`RhythmSkillSystem.js` 第525行 `ctx.stroke()` 之后，`activeRings.push(ring)` 之前

**新增逻辑**：

```
// 环内半透明青色遮罩（与联连技冲击波同款结构）
if (ring.color === '#00FFFF') {  // 仅青色环加遮罩
    var settleMaskAlpha = ringAlpha * 0.12;
    ctx.fillStyle = 'rgba(0, 255, 255, ' + settleMaskAlpha.toFixed(3) + ')';
    ctx.beginPath();
    ctx.arc(ringCx, ringCy, ringRadius * 0.85, 0, Math.PI * 2);
    ctx.fill();
}
```

**参数取值说明**：
| 参数 | 值 | 理由 |
|------|-----|------|
| 条件 | `ring.color === '#00FFFF'` | 仅给青色环加遮罩，金色/紫色环跳过（保持结算华丽感，避免色块混杂） |
| 透明度 | `ringAlpha * 0.12` | 跟随环自身的 alpha 衰减，峰值 0.12 |
| 填充半径 | `ringRadius * 0.85` | 与联连技一致 |

**可选增强**：如果测试后觉得单层遮罩太弱，可以在金环上也加淡金遮罩：

```
if (ring.color === '#FFD700') {
    var settleGoldMaskAlpha = ringAlpha * 0.08;
    ctx.fillStyle = 'rgba(255, 215, 0, ' + settleGoldMaskAlpha.toFixed(3) + ')';
    ctx.beginPath();
    ctx.arc(ringCx, ringCy, ringRadius * 0.85, 0, Math.PI * 2);
    ctx.fill();
}
```

## 视觉效果示意

### 修改前
```
步骤1: 绘制青色外环 ○
步骤2: 绘制白色内环 ○（半径85%处）
结果: 只有两个环线，环内完全透明
```

### 修改后
```
步骤1: 绘制青色外环 ○
步骤2: 绘制环内青色半透明遮罩 ●（填充到半径85%处，透明度0.12）
步骤3: 绘制白色内环 ○（半径85%处）
结果: 冲击波有明显的"面"感，不再只是线
```

## 风险评估

| 风险项 | 等级 | 说明 |
|--------|------|------|
| 性能 | 无风险 | 仅增加1-2次 fillRect 等价操作，Canvas 2D 毫无压力 |
| 视觉冲突 | 极低 | 透明度仅 0.12，且跟随环同步衰减，不会遮挡其他元素 |
| 回归 | 无 | 纯增量代码，不修改任何现有逻辑 |
