# 空格键触发灵光方案

## 一、需求概述

玩家在编队面板中将某个已装备灵光指定为"空格灵光"。战斗中该灵光照常随机生成在舞台上，玩家除了可以点击它，还可以直接按空格键触发它——无论灵光在舞台上的哪个位置。

当玩家首次获得闪避灵光时，触发空格灵光装备引导教程。

## 二、不改变的内容

- 灵光生成机制完全不变（频率、位置、类型池均不动）
- 触摸/鼠标点击灵光的原有行为完全不变
- `equippedStars` 管理方式不变
- `StarSystem`、`BattleEngine`、`ChargeSystem` 内部逻辑不变

## 三、方案设计

### 3.1 空格灵光绑定

存档新增字段：

```
pd.spaceKeyStar = null | 灵光ID
```

必须是 `pd.equippedStars` 中的灵光类型。

#### 编队面板 UI

在 `SquadRenderer.js` 已装备槽位中，点击槽位可将其设为"空格灵光"（已有 5 个槽位，选一个标为空格键触发）。同时只能有一个。

### 3.2 触发逻辑

```
空格按下 (keydown, !e.repeat)
  → 条件检查（战斗状态、未被硬控、节奏技未激活、pd.spaceKeyStar 非空）
  → 遍历 stars[]，找第一个 type === pd.spaceKeyStar && visible === true 的灵光
  → 找到 → 调用 BattleEngine.handleStarClick(那颗灵光的位置)
  → 没找到 → 不响应
```

### 3.3 长按蓄力

空格按住超过 150ms → 若蓄力已解锁 → 对找到的那颗灵光进入蓄力状态（对接 `ChargeSystem.beginMonitoring()`）。松手释放。

灵光在舞台上原地进入蓄力动画，视觉效果与触摸 D2 蓄力一致。

### 3.4 空格灵光装备引导教程

#### 3.4.1 触发时机

玩家首次获得闪避灵光时触发。闪避灵光的获取途径是：与猫灵 NPC 对话第 3 次，选择 `'care'` 选项（`NpcDialogueConfig.js` 第 82 行 `unlockedStarTypes.push('dodge')`）。

在 `onChoice` 回调中，`unlockedStarTypes.push('dodge')` 之后，额外检测：

```
if (!pd._spaceKeyTutorialShown) {
    pd._spaceKeyTutorialShown = true;
    return { toast: '获得闪避灵光！', showSpaceKeyTutorial: true };
}
```

#### 3.4.2 引导流程

```
获得闪避灵光 (toast 提示)
  → 返回大地图
  → 自动打开编队面板（Squad 标签）
  → 高亮闪烁刚获得的闪避灵光
  → 弹出引导气泡箭头指向该灵光，提示：
    「你可以将灵光设为空格键触发！点击槽位即可设定。」
  → 玩家点击槽位将闪避灵光设为空格灵光
  → pd.spaceKeyStar = 'dodge'
  → 引导完成，气泡消失
```

#### 3.4.3 引导 UI

复用现有 `DialogueSystem` 的 `guide_anim` 模式或简化版气泡（带箭头指向目标槽位）。不引入新的弹窗机制。

引导过程不阻断玩家其他操作（非模态），如果玩家直接关闭编队面板或不操作，引导标记为已完成——下次不会再触发。

#### 3.4.4 状态记录

```
pd._spaceKeyTutorialShown: true   // 引导已触发过，不再重复
```
