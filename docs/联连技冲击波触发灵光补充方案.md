# 联连技冲击波触发灵光（补充方案）

> 已落地基础框架：`enterJudging` 创建冲击波环 + 闪白，`render` 中从屏幕中心扩散。
> 本补充方案将冲击波改造为以触发灵光为中心，并扫过场上灵光时引爆为流星。

---

## 一、当前实现 vs 目标

| | 当前实现 | 目标 |
|------|---------|------|
| 冲击波中心 | `(screenW/2, screenH/3)` 屏幕固定中心 | 联连窗口的第 1 颗灵光（触发灵光）位置 |
| 冲击波效果 | 纯视觉圆环扩散 | 扩散过程中检测碰撞：扫过灵光 → 引爆为流星 |
| 场上其他灵光 | 不受联连技影响（只有 linkedStars 被消耗） | 冲击波扫过的非联连灵光 → 化为流星飞向怪物 |

## 二、冲击波中心改为触发灵光位置

### 2.1 改动点

`enterJudging` 中记录触发灵光位置到 `state.shockwaveOrigin`，`render` 中读取。

```js
// LinkChainSystem.js — enterJudging() 中添加:
state.shockwaveOrigin = { x: state.linkedStars[0].x, y: state.linkedStars[0].y };

// render() — 冲击波绘制部分:
var ringCx = state.shockwaveOrigin ? state.shockwaveOrigin.x : screenW / 2;
var ringCy = state.shockwaveOrigin ? state.shockwaveOrigin.y : screenH / 3;
```

`state.shockwaveOrigin` 在 `reset()` 中清空。

## 三、冲击波扫过灵光 → 引爆为流星

### 3.1 触发机制

冲击波在扩散过程中，每帧检测所有场上灵光到冲击波中心的距离。若灵光进入当前冲击波半径范围（考虑环宽），则触发引爆。

**参考实现**：`RhythmSkillSystem.detonateStars()` 已有完全一致的逻辑——遍历所有场上灵光，为每颗创建流星飞向最近怪物。

### 3.2 检测规则

- **排除联连窗口灵光**：`_linking` 标记的灵光不引爆（它们正在联连流程中被消耗）。
- **排除已被其他系统占用的灵光**：`_charging`、`_dragging`、`_rhythm` 标记的跳过。
- **每颗灵光只引爆一次**：可在灵光上临时标记 `_shockwaveTriggered`。

### 3.3 实施位置

在 `render()` 的冲击波绘制循环中，或新增一个 `update()` 中调用的检测函数。推荐放在 `update()` 中，便于集中管理。

```js
// LinkChainSystem.js — update() 中，shockwaveRings 绘制前:
function detectShockwaveStarHits(now) {
    for (var ri = 0; ri < state.shockwaveRings.length; ri++) {
        var ring = state.shockwaveRings[ri];
        var ringElapsed = now - ring.startTime;
        if (ringElapsed < 0 || ringElapsed >= ring.duration) continue;

        var ringProgress = ringElapsed / ring.duration;
        var ringRadius = ring.startRadius + (ring.endRadius - ring.startRadius) * ringProgress;

        var ox = state.shockwaveOrigin ? state.shockwaveOrigin.x : getScreenWidth() / 2;
        var oy = state.shockwaveOrigin ? state.shockwaveOrigin.y : getScreenHeight() / 3;

        var stars = getStars();
        for (var si = 0; si < stars.length; si++) {
            var s = stars[si];
            if (s._linking || s._charging || s._dragging || s._rhythm) continue;
            if (s._shockwaveTriggered) continue;

            var dx = s.x - ox;
            var dy = s.y - oy;
            var dist = Math.sqrt(dx * dx + dy * dy);

            // 灵光在冲击波环当前半径范围内 → 命中
            if (dist <= ringRadius) {
                s._shockwaveTriggered = true;
                triggerStarMeteor(s);
            }
        }
    }
}
```

### 3.4 流星创建

复用 `createMeteor`（RhythmSkillSystem 中已注入的相同 API）。LinkChainSystem 需要新增依赖注入 `createMeteor`：

```js
// game.js — createLinkChainSystem 注入新增:
createMeteor: function(sx, sy, dmg, crit, st, ss, cm, cb, customEnd) {
    createMeteorAnimation(sx, sy, dmg, crit, st, ss, cm, cb, customEnd);
}
```

调用方式（参考 `detonateStars`）：

```js
function triggerStarMeteor(star) {
    var monsters = getActiveMonsters();
    if (!monsters || monsters.length === 0) return;

    // 找最近怪物
    var nearest = null;
    var nearestDist = Infinity;
    for (var m = 0; m < monsters.length; m++) {
        var mon = monsters[m];
        if (mon.hp <= 0 || !mon.active) continue;
        var mdx = (mon.x || 0) - star.x;
        var mdy = (mon.y || 0) - star.y;
        var dist = mdx * mdx + mdy * mdy;
        if (dist < nearestDist) { nearestDist = dist; nearest = mon; }
    }

    if (!nearest || !createMeteor) return;

    var sw = getScreenWidth ? getScreenWidth() : 375;
    var sh = getScreenHeight ? getScreenHeight() : 667;
    var pd = getSaveData();
    var baseAtk = pd.totalAttack || 50;
    var dmg = Math.floor(baseAtk * 0.5);  // 流星伤害 = 50% 攻击力（可调）

    createMeteor(
        star.x, star.y,
        dmg, false,
        star.type || 'normal',
        0, 1,
        function() {
            if (nearest.hp > 0) {
                if (nearest.shield > 0) {
                    if (dmg <= nearest.shield) { nearest.shield -= dmg; }
                    else { dmg -= nearest.shield; nearest.shield = 0; nearest.hp = Math.max(0, nearest.hp - dmg); }
                } else {
                    nearest.hp = Math.max(0, nearest.hp - dmg);
                }
            }
        },
        { x: nearest.x || sw / 2, y: nearest.y || sh / 3, heroic: true }
    );

    // 标记灵光消失
    star.disappearTime = Date.now() - 1;
}
```

**注意**：`detonateStars` 中对流星伤害变量使用了 IIFE 闭包保护（`(function(dmgCopy, ...) { ... })(dmg, ...)`），防止 `settle()` 的循环中变量被覆盖。`triggerStarMeteor` 由于是独立函数调用（每次调用都有独立作用域），不需要 IIFE 保护。但如果后续将触发逻辑放在循环中直接调用，建议加上 IIFE 保护。

### 3.5 伤害设计建议

联连技主伤害已经是 `baseAtk × multiplier` 的全屏伤害，冲击波流星是**额外视觉/伤害层**。建议：

- 每颗流星伤害 = `baseAtk × 0.3 ~ 0.5`（轻量，避免数值膨胀）
- 或使用 `normalBattleAdapter` 中的 `calculateStarScore` 计算灵光基础伤害

### 3.6 清理 `_shockwaveTriggered` 标记

`_shockwaveTriggered` 标记设置在灵光对象上（灵光是共享数组中的元素），不属于 LinkChainSystem 内部 state。`reset()` 中需要清理：

```js
// reset() 中追加:
var stars = getStars();
for (var i = 0; i < stars.length; i++) {
    delete stars[i]._shockwaveTriggered;
}
```

## 五、不做的部分

- **联连窗口中的灵光（`_linking`）**：已由联连技消耗，不引爆。
- **Boss 灵光 / 塔灵光**：如果它们没有被 `_linking/_charging/_dragging/_rhythm` 标记则正常引爆，行为一致。
- **冲击波速度差异化**：暂不做，所有冲击波层共用同一半径进度。
