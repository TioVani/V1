# 猫灵对话系统 — 落地方案（统一配置驱动架构）

## 一、需求概要

world_02（蜀汉城·居民小巷）坐标 x=1237 y=720，玩家通过新手战斗后猫灵 ML.png 藏在此处。玩家可反复与她交互（去其他地图后再回来即可），总共3次+的访问触发不同对话流程。

### 对话状态机

```
第1次访问 → 猫灵:"喵。"
  玩家选择: 你好~ | 喵喵喵？
  → 记录 choice1

第2次访问 → 猫灵:"喵喵喵？"
  玩家选择: 你好~ | 喵喵喵？
  → 记录 choice2

第3次访问（根据 choice1 + choice2 组合分支）:
  choice1=你好 + choice2=你好 → 猫灵:"喵喵喵。"
  choice1=喵喵喵 + choice2=喵喵喵 → 猫灵:"干嘛三番五次套近乎？"
  一好一喵（任意顺序）→ 猫灵:"喵三喵四喵喵喵？"

  玩家选择:
    没啥。→ 结束，无奖励
    看看你有没有受伤。→ 送闪避灵光（unlockedStarTypes.push('dodge')）

第4+次访问 → 已给过奖励: "喵~（猫灵冲你眨了眨眼）"
              没给过奖励: "……"
```

## 二、架构设计

### 核心原则

**所有NPC对话逻辑收敛到 `NpcDialogueConfig.js` 配置层，game.js 只做通用编排，不为特定NPC写判断分支。**

### 新增/改动文件

| 文件 | 改动类型 | 职责 |
|------|---------|------|
| `V1/src/config/NpcDialogueConfig.js` | **新建** | NPC对话驱动器注册表 + 纯函数对话生成 |
| `V1/src/config/WorldMapConfig.js` | 修改 | world_02 新增 npc_cat_spirit 实体 |
| `V1/src/renderers/WorldMapRenderer.js` | 修改 | 对话支持 `{ text, choices }` 格式 + 选项热区 |
| `V1/src/systems/GameDataStore.js` | 修改 | saveData 新增 `npcDialogState` 字段 |
| `V1/game.js` | 修改 | NPC交互统一编排 + 选项点击事件接入 |

### 数据流

```
E键/触摸交互
  → WorldMapEntity.interact(entityId)
    → onInteractResult({ type: 'npc', entity, dialogue })
      → game.js 检测 entity.npcDialogueDriver
        → NpcDialogueConfig[driver].getScript(pd, stateId)
          → 返回 [{ text, choices? }, ...]
        → worldMapRenderer.showDialogue(script, onChoiceCallback)
          → 用户点击选项
            → advanceDialogue(choiceKey)
              → onChoiceCallback(choiceKey)
                → NpcDialogueConfig[driver].onChoice(pd, stateId, choiceKey)
                  → 更新存档状态
                  → 发放奖励（如果触发）
                → saveProgress()
```

### 与现有模式的统一

```
现有模式:                   统一后:
DialogueConfig.js          DialogueConfig.js (cutscene)
  └─ SceneDispatcher         └─ SceneDispatcher
                           NpcDialogueConfig.js (大地图NPC对话)  ← 新增
                             └─ game.js (通用编排)
```

两者都是"配置即文档"的纯净数据层，差异只在调度方式（cutscene 走 SceneDispatcher，大地图NPC走 game.js 的通用 handler）。

## 四、NpcDialogueConfig.js — 猫灵完整配置

```javascript
/**
 * NpcDialogueConfig — 大地图NPC对话驱动器注册表
 * 每个 driver 自包含：状态初始化 + 对话生成 + 选择响应。
 * 新增NPC对话只需在此文件加一条注册项，不改 game.js。
 */

export const NPC_DIALOGUE_DRIVERS = {
    // ── 猫灵（world_02）────────────────────────────
    cat_spirit: {
        initState: function () {
            return {
                visitCount: 0,
                choice1: null,
                choice2: null,
                gaveReward: false,
                resolved: false
            };
        },

        getScript: function (state) {
            var v = state.visitCount;

            // 第3次已结束，后续访问
            if (state.resolved) {
                if (state.gaveReward) {
                    return [{ text: '喵~（猫灵冲你眨了眨眼）' }];
                }
                return [{ text: '……' }];
            }

            // 第1次
            if (v === 0) {
                return [{
                    text: '喵。',
                    choices: [
                        { label: '你好~', key: 'hello' },
                        { label: '喵喵喵？', key: 'meow' }
                    ]
                }];
            }

            // 第2次
            if (v === 1) {
                return [{
                    text: '喵喵喵？',
                    choices: [
                        { label: '你好~', key: 'hello' },
                        { label: '喵喵喵？', key: 'meow' }
                    ]
                }];
            }

            // 第3次 —— 根据前两次选择决定台词
            var c1 = state.choice1;
            var c2 = state.choice2;
            var thirdLine;
            if (c1 === 'hello' && c2 === 'hello') {
                thirdLine = '喵喵喵。';
            } else if (c1 === 'meow' && c2 === 'meow') {
                thirdLine = '干嘛三番五次套近乎？';
            } else {
                thirdLine = '喵三喵四喵喵喵？';
            }

            return [{
                text: thirdLine,
                choices: [
                    { label: '没啥。', key: 'nothing' },
                    { label: '看看你有没有受伤。', key: 'care' }
                ]
            }];
        },

        onChoice: function (pd, stateId, state, choiceKey) {
            var v = state.visitCount;

            if (v === 0) {
                state.choice1 = choiceKey;
                state.visitCount = 1;
            } else if (v === 1) {
                state.choice2 = choiceKey;
                state.visitCount = 2;
            } else if (v === 2) {
                if (choiceKey === 'care') {
                    // 发放闪避灵光
                    if (!pd.unlockedStarTypes) pd.unlockedStarTypes = [];
                    if (pd.unlockedStarTypes.indexOf('dodge') === -1) {
                        pd.unlockedStarTypes.push('dodge');
                    }
                    state.gaveReward = true;
                    state.visitCount = 3;
                    state.resolved = true;
                    return { toast: '获得闪避灵光！你已解锁闪避灵光。' };
                }
                state.visitCount = 3;
                state.resolved = true;
            }

            return null;
        }
    }

    // 未来新增NPC只需在这里添加新 driver，
    // 然后在 WorldMapConfig 中配置 npcDialogueDriver 字段即可。
};
```

## 五、WorldMapRenderer — 对话系统扩展

### 内部数据结构变更

```javascript
// _dialogue 结构扩展
// 原来: { lines: string[], index: number }
// 扩展: { lines: Array<string|{text,choices}>, index: number }
// 
// lines[i] 可以是:
//   字符串 "纯文本行"
//   对象 { text: "台词", choices: [{ label: "选项1", key: "key1" }, ...] }
//   choices 可选，不存在即普通行

var _choiceHotspots = [];  // [{ x, y, w, h, key, sw, sh }, ...]
// 存储最近一次渲染的选项按钮热区，供 game.js 点击检测
```

### showDialogue 改造

```javascript
function showDialogue(lines, callback) {
    _dialogue = { lines: lines, index: 0 };
    // 将旧 callback (无参, 对话结束时触发) 改为 options callback
    // callback(choiceKey) — 每次选择时触发
    // 兼容旧调用: 如果旧代码传了 callback 但没用到 choiceKey，行为不变
    _dialogueCallback = callback;
    _choiceHotspots = [];
}
```

### advanceDialogue 改造

```javascript
function advanceDialogue(choiceKey) {
    if (!_dialogue) return null;

    var cur = _dialogue.lines[_dialogue.index];
    
    // 当前行有选项但没传 choiceKey → 等待用户点击选项（不推进）
    if (cur && typeof cur === 'object' && cur.choices && cur.choices.length > 0 && choiceKey === undefined) {
        return cur;
    }

    // 有选项且传了 choiceKey，通知回调
    if (_dialogueCallback && choiceKey !== undefined) {
        _dialogueCallback(choiceKey);
    }

    _dialogue.index++;

    // 对话结束
    if (_dialogue.index >= _dialogue.lines.length) {
        // 如果之前每句都通过选项推进，最后一行结束后不需要再触发一次回调
        dismissDialogue();
        return null;
    }

    _choiceHotspots = [];
    return _dialogue.lines[_dialogue.index];
}
```

### dismissDialogue 改造

```javascript
function dismissDialogue() {
    _dialogue = null;
    _dialogueCallback = null;
    _choiceHotspots = [];
}
```

### 选项按钮渲染（在 _renderDialogue 段落中）

当前渲染代码在 `renderWorldMap` 中（约第499行起）。在现有对话框渲染逻辑末尾，文本绘制完后增加选项按钮渲染。

```javascript
// 绘制选项按钮（在"点击继续"提示之前）
var curLine = _dialogue.lines[lineIdx];
if (curLine && typeof curLine === 'object' && curLine.choices && curLine.choices.length > 0) {
    _choiceHotspots = [];
    var btnW = Math.floor((dlgW - padding * 3) / 2);  // 两按钮并排
    var btnH = Math.floor(38 * uiScale);
    var btnY = dlgY + dlgH - btnH - Math.floor(25 * uiScale);
    var btnGap = Math.floor(8 * uiScale);

    for (var bi = 0; bi < curLine.choices.length; bi++) {
        var btnX = dlgX + padding + bi * (btnW + btnGap);

        // 按钮背景
        ctx.fillStyle = 'rgba(232,213,163,0.15)';
        ctx.strokeStyle = '#e8d5a3';
        ctx.lineWidth = Math.floor(1.5 * uiScale);
        var bdr = Math.floor(6 * uiScale);
        ctx.beginPath();
        ctx.moveTo(btnX + bdr, btnY);
        ctx.lineTo(btnX + btnW - bdr, btnY);
        ctx.arcTo(btnX + btnW, btnY, btnX + btnW, btnY + bdr, bdr);
        ctx.lineTo(btnX + btnW, btnY + btnH - bdr);
        ctx.arcTo(btnX + btnW, btnY + btnH, btnX + btnW - bdr, btnY + btnH, bdr);
        ctx.lineTo(btnX + bdr, btnY + btnH);
        ctx.arcTo(btnX, btnY + btnH, btnX, btnY + btnH - bdr, bdr);
        ctx.lineTo(btnX, btnY + bdr);
        ctx.arcTo(btnX, btnY, btnX + bdr, btnY, bdr);
        ctx.closePath();
        ctx.fill();
        ctx.stroke();

        // 按钮文字
        ctx.fillStyle = '#e8d5a3';
        ctx.font = 'bold ' + Math.floor(14 * uiScale) + 'px sans-serif';
        ctx.textAlign = 'center';
        ctx.textBaseline = 'middle';
        ctx.fillText(curLine.choices[bi].label, btnX + btnW / 2, btnY + btnH / 2);

        // 记录热区（屏幕坐标）

            x: btnX, y: btnY, w: btnW, h: btnH,
            key: curLine.choices[bi].key
        });

    // 隐藏"点击继续"提示（选项模式下不显示）
    // 在原有代码 renderHint 段判断 _choiceHotspots.length > 0 时跳过
```

### 新增公开接口

```javascript
return {
    // ... 现有接口 ...
    getChoiceHotspotAt: function (x, y) {
        // x, y 为屏幕坐标（来自 touch/mouse 事件）
        for (var i = 0; i < _choiceHotspots.length; i++) {
            var hs = _choiceHotspots[i];
            if (x >= hs.x && x <= hs.x + hs.w && y >= hs.y && y <= hs.y + hs.h) {

            }
        }
        return null;
```

### 新增 _handleNpcDialogue 函数

```javascript
function _handleNpcDialogue(driverId) {
    var drv = _gameModules.NPC_DIALOGUE_DRIVERS[driverId];
    var pd = saveData;

    // 初始化状态
    if (!pd.npcDialogState) pd.npcDialogState = {};
    if (!pd.npcDialogState[driverId]) {
        pd.npcDialogState[driverId] = drv.initState();
    }
    var state = pd.npcDialogState[driverId];

    // 生成对话脚本
    var script = drv.getScript(state);
    if (!script || script.length === 0) return;

    // 显示对话，注册选择回调
    worldMapRenderer.showDialogue(script, function (choiceKey) {
        if (choiceKey) {
            var result = drv.onChoice(pd, driverId, state, choiceKey);
            if (result && result.toast) {
                $P.showToast({ title: result.toast, icon: 'success', duration: 2500 });
            }
            worldMapSystem.saveProgress();
        }
    });
}
```

```javascript
// 优先处理对话选项点击（在 isDialogueOpen 检测之后、实体交互之前）
```

## 七、猫灵可见性控制

猫灵需要在新手战斗完成后才出现在 world_02。控制方式：

### 方案A：通过 _hiddenEntityIds（推荐）

`WorldMapEntity.setHiddenEntityIds` 存在但 `WorldMapSystem` 目前**未暴露**此接口。需要两步：

**步骤1：WorldMapSystem 新增暴露**（在 return 对象中加一行）：

```javascript
setHiddenEntityIds: function(ids) { entity.setHiddenEntityIds(ids); },
```

**步骤2：game.js 中 loadWorld 后管理可见性**：

```javascript
// 在 worldMapSystem.loadWorld 之后
if (worldId === 'world_02') {
    var pd = saveData;
    var catTaskDone = pd.taskProgress && pd.taskProgress.guide 
        && pd.taskProgress.guide['guide_find_cat_spirit'] 
        && pd.taskProgress.guide['guide_find_cat_spirit'].claimed;
    if (!catTaskDone) {
        worldMapSystem.setHiddenEntityIds(['npc_cat_spirit']);
    } else {
        worldMapSystem.setHiddenEntityIds([]);
    }
}
```

### 方案B：通过 entity.once + 手动控制（备选）

如果不想改 `setHiddenEntityIds`，可将猫灵设为 `once: true`，任务完成后手动 `unresolveEntity`。但这个方式在跨地图回来时会重置，不如方案A可靠。

**推荐方案A**，因为 `setHiddenEntityIds` 已经在 WorldMapUnlock 的 barrier 解除逻辑中有使用先例（`if (e.hiddenEntityIds && e.hiddenEntityIds.length > 0)`），API 是稳定的。

### 或者更简单：不控制可见性，改为控制交互结果

猫灵始终可见，但交互时检测条件不足，弹 toast 提示"猫灵还没出现……"。

**推荐用方案A**，用户体验更好（看不到=不会产生困惑）。

```javascript
function _migrateIncomingSaveData(data) {
    var merged = deepClone(defaultSaveData);  // 包含 npcDialogState: null
    for (var key in data) {
        if (data.hasOwnProperty(key)) {
            merged[key] = deepClone(data[key]);
        }
    }
    merged._version = 3;
    return merged;
}
```

## 十一、风险提示

1. **WorldMapRenderer 选项渲染需要验证移动端适配**：按钮大小用 `uiScale` 计算，需在多种屏幕尺寸下测试
2. **键盘用户无法选择选项**：当前设计选项只能鼠标/触摸点击。如需键盘支持，后续可在 E 键事件中加入 1/2 数字键映射或 Tab 切换焦点
3. **`setHiddenEntityIds` 全局单一调用**：如果未来多个 barrier 也在用，需要合并而非覆盖。可在 WorldMapSystem 中改为追加式而非替换式
