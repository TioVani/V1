# 分辨率自适应系统性问题审计报告

## 设计体系说明

项目基于 `DESIGN_WIDTH=375`, `DESIGN_HEIGHT=812` 设计基准:
- **`getScreenScale()`**: 水平缩放 = `max(0.7, screenWidth / 375)`，控制元素尺寸
- **`getDesignOffsetY()`**: 垂直居中偏移 = `max(0, (screenHeight - 812*scale) / 2)`，高屏幕时内容区从屏幕中部开始

**正确公式**: `Y坐标 = designOffsetY + Math.floor(值 * scale)`
**错误公式**: `Y坐标 = Math.floor(值 * scale)` — 缺少 designOffsetY，高屏幕上内容挤在顶部

5. **`WorldMapRenderer.js`** — HUD 偏移轻微，优先级低
6. **`DebugRenderer.js`** — 调试工具，优先级最低
