# 闪避灵光引导气泡优化方案

## 问题描述

玩家首次获得闪避灵光后，编队面板中出现黄色引导气泡，存在以下三个问题：

1. **位置不当**：引导气泡绘制在装备槽位区域正下方的滚动列表顶部（`separatorY + 10*scale`），直接遮挡闪避灵光所在行和"装备"按钮，玩家看不到要操作的目标。

2. **文字溢出**：引导文案 `"获得闪避灵光！点击装备后，再点击装备槽位设为空格键触发。"` 按 12*scale 字号在约 280*scale 宽度的气泡内远超一行，但当前代码只用单行 `fillText` 渲染，导致文字超出气泡边界约 5 个字。

3. **点击被拦截**：气泡使用不透明黄色背景（`rgba(255, 215, 0, 0.9)`），但 `handleClick` 函数没有检测气泡区域。气泡下方的灵光行和按钮被视觉遮挡，玩家点击气泡位置时事件穿透到背后 UI，可能误触或无法操作。

三者叠加导致引导流程无法完成——玩家既看不清下面的灵光，也点不到装备按钮。

三个问题对应三处根因：

- **位置**：`bubbleY = separatorY + 10*scale` 把气泡放在分隔线下方紧贴滚动列表起点，恰好覆盖第一行灵光。
- **文字**：单次 `fillText` 不换行，气泡高度固定 50*scale 只够一行。
- **点击**：`handleClick` 中没有气泡区域的 hit-test 逻辑，气泡对点击完全不感知。

## 优化方案

### 1. 气泡下移到屏幕底部

**目标**：气泡移至编队面板底部空白区域，不遮挡灵光列表和任何可交互元素。

**具体变更**：

```
// 当前（挡住分隔线下面第一行灵光）
var bubbleY = separatorY + Math.floor(10 * scale);

// 优化后（放在编队面板底部，紧贴面板底边上方）
var bubbleY = designBottom - Math.floor(bubbleH + 15 * scale);
```

气泡位置与灵光滚动列表完全分离：
- 分隔线以上是固定槽位区（y ≈ 280~380）
- 分隔线以下是可滚动的灵光列表区（y ≈ 380~designBottom）
- 气泡放在面板底部（y ≈ designBottom - 65）

这样气泡不再遮挡任何灵光行或按钮，滚动列表仍然可以正常滚动和点击。

**副作用评估**：面板底部是空白区域（标签页最下方），不会遮挡其他 UI 元素。

### 2. 文字支持多行换行

**目标**：气泡内文字按气泡宽度自动换行，最多 2 行，超出截断加省略号。

**具体变更**：

将单次 `fillText` 替换为多行渲染函数：

```
ctx.font = 'bold ' + Math.floor(12 * scale) + 'px sans-serif';
ctx.textAlign = 'center';
ctx.textBaseline = 'top';

var fullText = '获得' + tutorialStar.name + '！点击装备后，再点击装备槽位设为空格键触发。';
var maxLineWidth = bubbleW - Math.floor(20 * scale);  // 左右各留 10*scale padding
var lines = wrapText(ctx, fullText, maxLineWidth, 2);  // 最多 2 行

var lineHeight = Math.floor(16 * scale);
var totalTextHeight = lines.length * lineHeight;
var startTextY = bubbleY + (bubbleH - totalTextHeight) / 2;  // 垂直居中

for (var li = 0; li < lines.length; li++) {
    ctx.fillText(lines[li], bubbleX + bubbleW / 2, startTextY + li * lineHeight);
}
```

新增 `wrapText` 工具函数（放在 `SquadRenderer.js` 中）：

```
// 按像素宽度拆分文字为多行
function wrapText(ctx, text, maxWidth, maxLines) {
    var lines = [];
    var currentLine = '';
    for (var i = 0; i < text.length; i++) {
        var testLine = currentLine + text[i];
        if (ctx.measureText(testLine).width > maxWidth && currentLine.length > 0) {
            lines.push(currentLine);
            if (lines.length >= maxLines) break;
            currentLine = text[i];
        } else {
            currentLine = testLine;
        }
    }
    if (currentLine && lines.length < maxLines) {
        lines.push(currentLine);
    }
    // 最后一行超长截断加省略号
    var lastLine = lines[lines.length - 1];
    if (lastLine && ctx.measureText(lastLine).width > maxWidth) {
        while (ctx.measureText(lastLine + '…').width > maxWidth && lastLine.length > 0) {
            lastLine = lastLine.slice(0, -1);
        }
        lines[lines.length - 1] = lastLine + '…';
    }
    return lines;
}
```

气泡高度同步调整为适合两行的尺寸：`bubbleH = Math.floor(60 * scale)`（原 50）。

**效果**：文案在两行内完整显示，不会溢出气泡边界。

### 3. 气泡区域点击拦截

**目标**：气泡区域内的点击事件被气泡消费，不穿透到背后的灵光列表 UI。

**具体变更**：

在 `handleClick` 函数中，`contentX`/`contentW` 变量定义之后（即 `var contentW = ...` 行之后）、stars tab 的 hit-test 区域之前插入气泡命中检测。注意仅在 stars tab 时生效（引导气泡只在灵光页显示）：

```
        // 内容区域
        var contentX = Math.floor(15 * scale);
        var contentW = screenWidth - tabWidth - contentX - Math.floor(15 * scale);

        // ★ 引导气泡点击拦截：若在气泡区域内，消费事件不穿透
        // 插入位置：contentW 定义之后
        if (tutorialActive && _tutorialHighlightStarId) {
            var bubbleStar = SEASON_STAR_TYPES.find(function(st) { return st.id === _tutorialHighlightStarId; });
            if (bubbleStar && getSquadTab() === 'stars') {
                var designBottom2 = designOffsetY + Math.floor(DESIGN_HEIGHT * scale);
                var bubbleH2 = Math.floor(60 * scale);
                var bubbleX2 = contentX + Math.floor(15 * scale);         // 与渲染: x + 15*scale 一致
                var bubbleW2 = contentW - Math.floor(30 * scale);         // 与渲染: w - 30*scale 一致
                var bubbleY2 = designBottom2 - Math.floor(bubbleH2 + 15 * scale);

                if (x >= bubbleX2 && x <= bubbleX2 + bubbleW2 && y >= bubbleY2 && y <= bubbleY2 + bubbleH2) {
                    return;
                }
            }
        }
```

注意：hit-test 坐标直接复用渲染中的参数来源（`contentX + 15*scale`、`contentW - 30*scale`），不再手算 `screenWidth - tabWidth - ...` 避免出错。

**效果**：玩家点击气泡时不会误触背后灵光列表中的按钮。

### 4. 气泡半透明 + 更明确的交互提示

**补充优化**：将气泡背景透明度从 0.9 降到 0.75，让玩家能隐约看到气泡下方面板底部区域（已无遮挡灵光列表），视觉上更友好。

```
ctx.fillStyle = 'rgba(255, 215, 0, 0.75)';
```

同时气泡文案可分两行显示：

```
第 1 行：「获得闪避灵光！」
第 2 行：「点击下方列表装备后，点击槽位设为空格键」
```

`wrapText` 按像素宽度自动换行即可实现，不需要硬编码换行符。

## 验证方法

1. 触发引导：与猫灵对话第 3 次选择"关心"，获得闪避灵光后打开编队面板。
2. 确认气泡出现在面板底部而非灵光列表顶部。
3. 确认气泡内文字分两行完整显示，无溢出。
4. 确认下方灵光列表可正常滚动，闪避灵光行和"装备"按钮可见可点击。
5. 确认点击气泡区域不会触发背后 UI。
6. 确认装备闪避灵光并设为空格键后气泡消失。
