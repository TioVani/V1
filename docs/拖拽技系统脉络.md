# 拖拽技（D3 Drag System）系统脉络

## 一、定位与核心循环

拖拽技是 D3 维度的"聚合→爆发"技，定位为衔接 D2 蓄力和 D4 联连节奏技之间的中程操作。核心循环：**拖拽吸附灵光 → 聚合叠层 → 指停转蓄力 / 松手触发拖拽技爆发**。

## 三、状态机

```
                    ┌──────────────────────────────────────────┐
                    │                                          │
                    ▼                                          │
    ┌──────┐  beginDrag()  ┌──────────┐  endDrag()  ┌──────────┤
    │ IDLE │──────────────▶│ DRAGGING │────────────▶│ COOLDOWN │
    └──────┘               └────┬─────┘             └────┬─────┘
       ▲                        │                        │
       │         闲置150ms       │      2秒后setTimeout    │
       │    transitionToCharge   │                        │
       │    ┌────────────────────┘                        │
       │    ▼                                             │
       │  finishDragTransition()                          │
       │  → D2 蓄力（带 dragBuff 加速）                    │
       └──────────────────────────────────────────────────┘
```

**各阶段行为：**

- **IDLE**：等待触摸。被定身（Boss root）时无法进入 DRAGGING。
- **DRAGGING**：手指在角色区域移动，路径碰撞灵光 → 吸附、标记 `_dragging`、发射流星。每帧检测闲置，超过 150ms 自动转蓄力。
- **COOLDOWN**：2 秒冷却，期间无法重新开始拖拽。冷却结束后回到 IDLE。

## 四、输入路由（TouchGestureSystem 协调层）

触摸事件不直连 DragSystem，而是通过 `TouchGestureSystem` 作为统一手势分类器：

```
touchstart
  ├── D4 联连窗口激活？ → D4_SWIPE（划链）
  ├── 命中灵光？
  │     ├── D2 已解锁 → D2_MONITOR（监控长按，150ms 后转蓄力）
  │     └── D2 未解锁 → D1_CLICK（短触点击）
  ├── 命中角色区域 + D3 已解锁？ → D3_DRAG（拖拽）
  └── 空白 → NONE

touchmove
  ├── D2_MONITOR → 滑动 > 15px？ → 切换为 D3_DRAG
  ├── D3_DRAG → updateDrag()，闲置 150ms → 切换为 D2_MONITOR（蓄力）
  └── D4_SWIPE → trackSwipePath()

touchend
  ├── D3_DRAG → endDrag()（聚合 ≥ 6 触发拖拽技爆发）
  └── D2_MONITOR → 释放蓄力 / 取消监控 / D1 回退
```

关键设计：**D2 监控中滑动 > 15px 可中途切为拖拽**，**拖拽中停指 > 150ms 可中途切为蓄力**。这两个阈值构成拖拽与蓄力之间的"软切换"。

## 五、吸附流程（每吸附一颗灵光时）

```
碰撞检测（距离 < hitRadius）
  │
  ├── 检查 saturatedState.canAbsorb()（体力 > 0？）
  │     └── 体力不足 → 提示"体力不足!"，本轮停止吸附
  │
  ├── 标记灵光 _dragging = true（防清理、防联连误触）
  ├── draggingStars 数组推入（渲染用）
  ├── currentAggregate++
  ├── dragStacks++（≤ 10，整局永久）
  ├── saturatedState.consume(8%)（扣体力）
  ├── addScore(5)
  ├── addLinkCharge(5)（充联连进度条）
  ├── 随机选取一只活怪 → 发射流星（累积伤害型）
  ├── addMessage("吸收 ⭐ 聚合×N")
  ├── vibrateShort（触觉反馈）
  │
  └── currentAggregate ≥ 6 → 本轮停止吸附
```

## 六、流星机制

每吸附一颗灵光，随机选取一只活着的怪物，从手指位置发射一颗流星飞向怪物位置。流星动画**复用 AnimationSystem 的通用流星系统**（与普通点击灵光发射的流星完全一致），包括五角星主体、径向渐变发光、弧线尾焰、尾迹粒子、命中爆炸等全套视觉效果。

- 飞行时长：150ms（通用流星标准）
- **伤害公式**：`floor(totalAttack × 1.5)`，随角色攻击力成长
- **即时结算**：流星飞到怪物时立即造成伤害（通过 AnimationSystem 的 `onHit` 回调）
- **累积追踪**：`cumulativeMeteorDamage` 累加每颗流星的实际伤害值，用于拖拽技爆发时的额外伤害结算

## 七、endDrag 松手结算（聚合数 ≥ 1）

松手时 **始终** 发射一颗"聚合本体流星"，拖拽技爆发是独立的全屏伤害。各聚合数行为如下：

```
endDrag() 触发：
  │
  ├── aggregateCount > 0 → 发射聚合本体流星（复用 AnimationSystem 通用流星）
  │     ├── 伤害 = aggregateCount × 30 × getAttackBonus()
  │     │   （1吸=30×1.05≈31 / 3吸=90×1.15≈103 / 6吸=180×1.3=234）
  │     ├── 满 6 吸时为暴击流星（isCritical=true）
  │     ├── onHit 回调即时结算怪物伤害
  │     └── addMessage("聚合灵光·N连! N伤害!")
  │
  ├── currentAggregate ≥ MAX_AGGREGATE（6颗）→ 拖拽技爆发（全屏伤害）
  │     ├── 遍历所有活怪 → attackMonster(cumulativeMeteorDamage)
  │     ├── addMessage("拖拽技! N伤害!")
  │     ├── addScore(50)
  │     └── addLinkCharge(40)
  │
  ├── 清除 _dragging 标记
  ├── 清空 draggingStars / cumulativeMeteorDamage
  └── 进入 2 秒冷却
```

**聚合本体流星伤害速查**（以 `totalAttack = 2834`，`dragStacks = aggregateCount` 为例）：

| 吸附数 | 公式 | 伤害 | 对标蓄力 |
|--------|------|------|---------|
| 1 | 1×2834×2.0×1.05 | 5,951 | 轻蓄 ×2.6 = 7,368 |
| 2 | 2×2834×2.0×1.10 | 12,470 | 中蓄 ×5.0(×3目标) = 14,170 |
| 3 | 3×2834×2.0×1.15 | 19,555 | — |
| 4 | 4×2834×2.0×1.20 | 27,206 | — |
| 5 | 5×2834×2.0×1.25 | 35,425 | — |
| 6 | 6×2834×2.0×1.30 | 44,210（暴击流星） | 满蓄 ×8.0 = 22,672 |

**吸附流星累计**：6颗 × `2834 × 1.5` = 25,506。**拖拽技全屏爆发** = cumulativeMeteorDamage = 25,506，对所有怪物同时造成。

**6吸完整总伤害**：吸附流星 25,506 + 聚合本体 44,210 + 全屏爆发 25,506 = **95,222**（满蓄 ×8.0 的 4.2 倍）

## 八、拖拽→蓄力过渡（闲置 150ms 时）

当手指在拖拽中停止移动 ≥ 150ms，且已聚合 ≥ 1 颗灵光：

```
dragSystem.update() 返回 { transitionToCharge: true, aggregate: N }
  │
  ├── chargeSystem.beginDragCharge(x, y, touchId, aggregate)
  │     ├── 充能起始时间前移：chargeStartTime = now - aggregate * 0.3 * CHARGE_FULL_MIN
  │     │   （每个聚合层数减 30% 充满时间，即加速蓄力）
  │     └── 无 chargeStar（灵光已全被拖拽消耗）
  │
  ├── touchGestureSystem.switchGestureToCharge()
  └── dragSystem.finishDragTransition()
        └── 清除 _dragging 标记，回到 IDLE
```

## 九、视觉效果

**拖拽锚点**：
- 外圈：金色圆环，半径 14px，半透明描边
- 内圈：金色填充圆，半径 6px

**聚合灵光**：以手指位置为中心螺旋排列，带旋转动画（角速度 = `Date.now()/500`），使用 `assets/images/LG.png` 图片 + `globalCompositeOperation='lighter'` 叠加效果（黑底自动透明）

**聚合标签**：手指上方 22px，`"聚合×N"`，金色粗体

**流星**：复用 AnimationSystem 通用流星动画（五角星主体 + 径向渐变发光 + 弧线尾焰 + 尾迹粒子 + 命中爆炸），与普通点击灵光发射的流星完全一致

## 十、与其他系统的交互矩阵

| 关联系统 | 关系 | 方向 |
|---------|------|------|
| **SaturationState（体力条）** | 每吸附一颗扣 8%，体力为 0 时阻止继续吸附 | 消耗 |
| **ChargeSystem（蓄力）** | 闲置 150ms 后自动过渡，叠加 dragBuff 加速蓄力 | 衔接 |
| **LinkChainSystem（联连）** | 每吸附 +5 进度，拖拽技爆发 +40 进度；联连系统跳过 `_dragging` 标记的灵光 | 供能 |
| **RhythmSkillSystem（节奏技）** | 节奏技重置时清除 `_dragging` 标记 | 互斥 |
| **NormalBattleAdapter（战斗计算）** | `getAttackBonus() = 1 + dragStacks * 0.05`，影响所有灵光伤害 | 全局 Buff |
| **BossRoot** | 被定身时阻止 `beginDrag()` | 打断 |
| **Score** | 每吸附 +5，拖拽技爆发 +50 | 得分 |

## 十一、当前已知问题与可优化点

1. **拖拽技爆发门槛过高**：必须聚合满 6 颗才有拖拽技，3-5 颗松手无额外收益，只获得流星累积伤害和层数。缺少中间奖励阶梯。
2. **拖拽技伤害单薄**：6 颗满聚合只有 420 伤害 + 50 分，与 D4 联连和节奏技的倍率体系相比缺乏竞争力。
3. **吸附无类型区分**：所有灵光（攻击、生存、增幅、特殊）一视同仁只 +5 分 +5 联连进度，没有差异化收益。
4. **闲置→蓄力的过渡信号弱**：手指停下 150ms 后静默切换，玩家可能感知不到已从拖拽转入蓄力。
5. **冷却期可操作性空窗**：2 秒冷却期间只能使用其他维度，没有 D3 专属的冷却期操作。
6. **层数 Buff 感知弱**：dragStacks 永久 +5% 攻击，但 UI 上无直观展示（仅在伤害计算时参与）。
7. **流星伤害延迟结算**：流星飞行 300ms 但实际伤害在松手时才发生，视觉与结算脱节。
8. **拖拽→蓄力后无法回到拖拽**：一旦闲置 150ms 转入蓄力，要松手才能重新开始拖拽，操作不灵活。
