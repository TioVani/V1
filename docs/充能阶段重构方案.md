# 联连与节奏技充能阶段重构方案

## 需求

- 充能 100：第一次联连窗口
- 充能 150：第二次联连窗口
- 充能 200：节奏技，如果联连窗口还在直接掐掉
- 能量条始终显示（idle → ready → rhythm_ready），无断层

## 设计原则

- **数据驱动**：阶段阈值定义在表中，不散落在逻辑分支里
- **单一决策点**：充能跨越阈值的判断集中在 `resolveChargePhase`
- **统一入口**：所有阶段切换走 `enterPhase`
- **消除重复**：ready 取消逻辑 `cancelReady` 被超时和充能掐断共用
- **封锁集中**：充能封锁阶段用数组管理

## 新增数据结构

### `CHARGE_PHASES` — 充能阶段定义表

放在文件顶部常量区（`D4_UNLOCK_LEVEL` 附近）。

```javascript
/**
 * 充能阶段定义表（按 threshold 升序排列）
 * phase: 目标阶段名
 * threshold: 触发阈值，充能从前一阶段跨越此值即触发
 * enter: 进入函数名（由 enterPhase 分发）
 * priority: 同一帧内多次跨越时，取最高优先级（数字越大越优先）
 */
var CHARGE_PHASES = [
    { phase: 'ready',         threshold: 100, enter: 'enterReady',        priority: 1 },
    { phase: 'ready',         threshold: 150, enter: 'enterReady',        priority: 1 },
    { phase: 'rhythm_ready',  threshold: 200, enter: 'enterRhythmReady',  priority: 2 },
];
```

### `CHARGE_BLOCKED_PHASES` — 充能封锁阶段列表

```javascript
/**
 * 处于这些阶段时禁止充能
 */
var CHARGE_BLOCKED_PHASES = ['revealing', 'waiting', 'swiping', 'judging', 'rhythm_ready'];
```

## 新增辅助函数

### `canCharge()` — 是否允许充能

```javascript
function canCharge() {
    if (!isUnlocked()) return false;
    if (CHARGE_BLOCKED_PHASES.indexOf(state.phase) !== -1) return false;
    if (rhythmSkillSystem && rhythmSkillSystem.isActive()) return false;
    return true;
}
```

替换 `addCharge()` 开头的 `if (!isUnlocked()) return` + `if (state.phase === ... || ...)` + `if (rhythmSkillSystem.isActive())` 三段判断。

### `resolveChargePhase(prev, next)` — 充能跨越解析

```javascript
/**
 * 检查充能从 prev 到 next 跨越了哪些阶段阈值。
 * 返回触发的最小阈值对应项（即充能途中第一个跨过的阶段）。
 *
 * 由于同一帧内一次充能可能跨越多个阈值（如 +100 从 50 冲到 150），
 * 返回的是阈值最小的命中项，阶段切换由后续逻辑链式处理。
 */
function resolveChargePhase(prev, next) {
    for (var i = 0; i < CHARGE_PHASES.length; i++) {
        var def = CHARGE_PHASES[i];
        if (prev < def.threshold && next >= def.threshold) {
            return def;
        }
    }
    return null;
}
```

### `cancelReady(reason)` — 统一取消联连 ready 窗口

```javascript
/**
 * 取消当前联连 ready 窗口，恢复触发灵光，回 idle。
 * 用于：(1) ready 超时 (2) 充能冲到 200 掐掉联连窗口
 */
function cancelReady(reason) {
    if (state.triggerStar) {
        state.triggerStar._linking = false;
        state.triggerStar.disappearTime = state.triggerStar._linkingOriginalDisappearTime || Date.now() + 5000;
        state.triggerStar = null;
    }
    addMessage(reason || '联连超时，继续充能...', '#ffaa00');
    state.phase = 'idle';
}
```

### `enterPhase(phaseName)` — 统一阶段切换入口

```javascript
/**
 * 统一的阶段切换入口。未来新增阶段只需在此加 case。
 */
function enterPhase(phaseName) {
    switch (phaseName) {
        case 'ready':
            return enterReady();
        case 'rhythm_ready':
            return enterRhythmReady();
        default:
            Logger.warn('[LinkChainSystem] enterPhase: unknown phase', phaseName);
    }
}
```

## 改动区域

### 改动 1：`addCharge()` — 重构

```javascript
function addCharge(amount) {
    if (!canCharge()) return;

    var prev = state.charge;
    state.charge = Math.min(RHYTHM_THRESHOLD, prev + amount);

    var triggered = resolveChargePhase(prev, state.charge);
    if (!triggered) return;

    // 如果当前处于 ready 且充能直接触发 rhythm_ready，先掐掉联连窗口
    if (state.phase === 'ready' && triggered.phase === 'rhythm_ready') {
        cancelReady('充能满溢! 联连窗口已跳过!');
    }

    enterPhase(triggered.phase);

    // 链式触发：enterPhase 可能改变 phase 但不改变 charge（如 enterReady），
    // 此时若 charge 仍跨越后续阈值，继续循环推进
    var safety = 0;
    while (safety < 10) {
        var next = resolveChargePhase(prev, state.charge);
        if (!next || next === triggered) break; // next === triggered 防同阈值重复触发
        triggered = next;

        if (state.phase === 'ready' && triggered.phase === 'rhythm_ready') {
            cancelReady('充能满溢! 联连窗口已跳过!');
        }

        enterPhase(triggered.phase);
        safety++;
    }
}
```

**注意**：`enterReady()` 不消费充能（`consumeLink` 只在 `beginLinkWindow` 即玩家点击触发灵光后调用）。因此 idle→200 一次充能跨越多个阈值时，靠 while 循环在同一帧内链式触发：先触发 ready(100)，再触发 ready(150)，最后触发 rhythm_ready(200)（掐掉联连窗口）。`safety < 10` 和 `next === triggered` 双重保护防止死循环。

## 状态流转验证

| 起始 | 充能后 charge | resolveChargePhase 命中 | 结果 |
|------|-------------|------------------------|------|
| idle, 0 | +5 → 5 | null | 无阶段切换 |
| idle, 95 | +5 → 100 | ready(100) | enterReady() |
| idle, 50 | +50 → 100 | ready(100) | enterReady() |
| idle, 100 | +50 → 150 | ready(150) | enterReady() |
| idle, 0 | +200 → 200 | ready(100) → ready(150) → rhythm_ready(200) | while 链式：enterReady → enterReady → cancelReady → enterRhythmReady |
| ready(150), 170 | +30 → 200 | rhythm_ready(200) | cancelReady → enterPhase('rhythm_ready') |
| ready(100), 120 | +80 → 200 | rhythm_ready(200) | cancelReady → enterPhase('rhythm_ready') |
| ready(100), 100 | 超时 2000ms | — | cancelReady → idle，charge 保持 100 |
