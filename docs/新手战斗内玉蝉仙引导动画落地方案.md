# 新手战斗内玉蝉仙引导动画落地方案

## 概述

在 tutorial 战斗中，玉蝉仙立绘从屏幕左下角滑入 → 说话气泡弹出引导文本 → 等待玩家首次点击灵光 → 气泡更新鼓励文本 → 玉蝉仙向右滑出屏幕。

本方案**不是独立系统**，而是 DialogueSystem 的一种新渲染模式 `guide_anim`。所有引导文字和触发时机统一存放在 `DialogueConfig.js` 的 `STORY_SCENES.prologue.inBattle` 中，由 `SceneDispatcher` 统一驱动。DialogueSystem 负责动画+气泡渲染。

---

## 设计原则

| 原则 | 实现 |
|------|------|
| **统一入口** | 战斗内引导和大地图剧情走同一个 DialogueSystem，只是 mode 不同 |
| **配置即文档** | 引导文字、触发时机、动画参数全在 `DialogueConfig.js` 的 `inBattle` 中 |
| **SceneDispatcher 驱动** | 不绕过 SceneDispatcher，`inBattle` 阶段由它接管触发器注册和生命周期 |

---

## 一、动画流程

```
战斗开始 (battle_start trigger)
  │
  ├─ [delayMs: 800]  玉蝉仙立绘从屏幕左下角开始向右滑入
  │                  动画曲线: ease-out, 持续时间 400ms
  │                  目标位置: 屏幕左侧 15%，底部对齐战斗画面底部
  │
  ├─ [滑入完成]       说话气泡弹出
  │                  内容: "来，先尝试点击一下灵光吧~"
  │                  位置: 玉蝉仙立绘右上方
  │
  ├─ [玩家首次点击灵光]
  │                  气泡内容切换为: "就是这样！！"
  │                  停留 800ms
  │
  └─ [800ms 后]       玉蝉仙立绘向右加速滑出屏幕
                     动画曲线: ease-in, 持续时间 300ms
                     气泡渐隐
```

---

## 二、架构设计

### 2.1 不新增文件

本方案不新增任何 JS 文件。改动仅集中在两个位置：

- **DialogueConfig.js**：`prologue.inBattle` 配置从 `mode: 'overlay'` 改为 `mode: 'guide_anim'`，新增 `guideAnim` 参数
- **DialogueSystem.js**：新增 `guide_anim` 模式的渲染分支（滑入/滑出动画 + 气泡渲染逻辑）

### 2.2 数据流

```
SceneDispatcher registerBattleTriggers(scene.inBattle)
  → 解析 inBattle.triggers
    → trigger { at: 'battle_start', delayMs: 800 }
      → 800ms 后调用 dialogueSystem.play({
           mode: 'guide_anim',
           guideAnim: scene.inBattle.guideAnim,
           lines: trigger.lines,          // ['来，先尝试点击一下灵光吧~']
         })

    → trigger { at: 'first_star_click' }
      → 点击后调用 dialogueSystem.advance(trigger.lines, trigger.waitFor)
        → 切换气泡文字为 "就是这样！！"
        → 停留 → 自动滑出

  → 动画结束后 dialogueSystem 内部回调 SceneDispatcher
```

### 2.3 与原有 mode 的关系

| mode | 行为 | 使用场景 |
|------|------|---------|
| `fullscreen` | 全屏不透明，独立背景，立绘在上对话在底 | 大地图剧情、战斗后剧情 |
| `overlay` | 半透明叠加，纯文字无立绘 | (保留，但 prologue 不再使用) |
| `guide_anim` | **新增**：单角色立绘 + 滑入/滑出动画 + 气泡 | 新手战斗引导、任何带角色演出的战斗内引导 |

DialogueSystem 在 `render()` 中根据 `_currentMode` 分支到不同的渲染函数。`guide_anim` 渲染逻辑内置在 DialogueSystem.js 中，**叠加**在已有战斗画面上（不绘制背景，game.js 的 TUTORIAL dispatch 已先调用 `renderGame()` 绘制了战斗画面）。

## 三、配置设计

### 3.1 DialogueConfig.js 中的 prologue.inBattle

```javascript
// V1/src/config/DialogueConfig.js

export const STORY_SCENES = {
  prologue: {
    id: 'prologue',
    name: '猫灵追逐·开场',

    preBattle: { script: PROLOGUE_DIALOGUE },

    inBattle: {
      mode: 'guide_anim',              // ← 改用 guide_anim
      guideAnim: {
        characterId: 'char_001',        // 玉蝉仙
        slideInFrom: 'left',            // 从左侧滑入
        slideOutTo: 'right',            // 向右侧滑出
        portraitWidth: 120,             // 立绘尺寸
        portraitHeight: 160,
        portraitTargetX: 0.15,          // 最终位置 (屏幕宽比例)
        portraitBottomOffset: 0.05,     // 底部留白 (屏幕高比例)
        slideInDuration: 400,           // 滑入时长 ms
        slideOutDuration: 300,          // 滑出时长 ms
        bubbleOffsetX: 10,             // 气泡相对立绘的 X 偏移
        bubbleOffsetY: -30,            // 气泡相对立绘的 Y 偏移
        bubbleMaxWidth: 200,            // 气泡最大宽度
        bubbleHoldAfterLast: 800,       // 最后一句后停留 ms 再滑出
      },
      triggers: [
        {
          at: 'battle_start',
          delayMs: 800,
          lines: ['来，先尝试点击一下灵光吧~'],
          waitFor: 'first_star_click',  // 本条之后等待 first_star_click 事件
        },
        {
          at: 'first_star_click',
          delayMs: 0,
          lines: ['就是这样！！'],
          waitFor: null,                // 最后一条，自动停留后滑出
        },
      ],
    },

    postBattle: {
      script: PROLOGUE_AFTER_BATTLE,
      onCompleteAction: { type: 'create_task', taskId: 'guide_find_cat_spirit' },
    },
  },
};
```

**关键字段说明**：

- `triggers[].lines`：每条 trigger 可以包含多行文字，替代了原来的 `script` + `lineIndex`
- `triggers[].waitFor`：本条触发后，文字显示完毕是否等待下一个事件。`null` 表示这是最后一条，自动停留后滑出
- `guideAnim.*`：所有视觉参数集中在 `guideAnim` 下，DialogueSystem 在 `guide_anim` 模式下读取这些参数

### 3.2 TUTORIAL_BATTLE_GUIDE 废弃

原 `TUTORIAL_BATTLE_GUIDE` 对话数组不再被引用。可以直接从 `DialogueConfig.js` 中删除，或用注释标记为废弃。

## 四、DialogueSystem 新增 guide_anim 模式

### 4.1 内部状态扩展

```javascript
// guide_anim 模式专用状态
var _guideState = {
    active: false,
    characterId: null,
    posX: 0, posY: 0,           // 立绘当前位置
    targetX: 0, targetY: 0,     // 立绘目标位置（render 首次调用时计算）
    startX: 0,                  // 滑入起点（render 首次调用时计算）
    opacity: 1,                 // 整体透明度
    bubbleText: '',             // 当前气泡文字
    bubbleOpacity: 0,           // 气泡透明度
    phase: 'idle',              // idle | sliding_in | showing | sliding_out
    phaseTimer: 0,              // 当前阶段已过时间 (ms)
    config: null,               // guideAnim 配置快照
    waitForEvent: null,         // 等待的事件名
    onComplete: null,           // 动画完成回调
    _needsCoordInit: false,     // play() 中标记，首次 render() 后清除
    _cachedScreenW: 0,          // render() 时缓存的屏幕尺寸
    _cachedScreenH: 0,
};
```

### 4.2 play() 扩展

```javascript
function play(opts) {
    // ... 原有 fullscreen / overlay 分支

    if (opts.mode === 'guide_anim') {
        var cfg = opts.guideAnim;
        var firstLine = opts.lines ? opts.lines[0] : '';
        _guideState.active = true;
        _guideState.characterId = cfg.characterId;
        _guideState.config = cfg;
        _guideState.bubbleText = firstLine;
        _guideState.waitForEvent = opts.waitFor || null;
        _guideState.onComplete = opts.onComplete || null;
        _guideState.phase = 'sliding_in';
        _guideState.phaseTimer = 0;
        _guideState.opacity = 1;
        _guideState.bubbleOpacity = 0;
        // 坐标延迟到首次 render() 时计算（此时 screenWidth/screenHeight 已知）
        _guideState._needsCoordInit = true;
        return;
    }

    // ... 其他 mode
}
```

**缓动函数**（定义在 DialogueSystem.js 内部，文件顶部常量区）：

```javascript
function easeOutCubic(t) { return 1 - Math.pow(1 - t, 3); }
function easeInCubic(t)  { return Math.pow(t, 3); }
```

### 4.3 update() 扩展

```javascript
function update(dt) {
    // ... 原有 fullscreen 模式更新逻辑

    if (!_guideState.active) return;

    _guideState.phaseTimer += dt * 1000; // dt 转 ms

    switch (_guideState.phase) {
        case 'sliding_in':
            var t = Math.min(1, _guideState.phaseTimer / _guideState.config.slideInDuration);
            _guideState.posX = _guideState.startX + (_guideState.targetX - _guideState.startX) * easeOutCubic(t);
            if (t >= 1) {
                _guideState.posX = _guideState.targetX;
                _guideState.phase = 'showing';
                _guideState.phaseTimer = 0;
            }
            break;

        case 'sliding_out':
            var outCfg = _guideState.config;
            var t2 = Math.min(1, _guideState.phaseTimer / outCfg.slideOutDuration);
            var outTargetX = outCfg.slideOutTo === 'right'
                ? _guideState._cachedScreenW + outCfg.portraitWidth
                : -outCfg.portraitWidth * 2;
            _guideState.posX = _guideState.targetX + (outTargetX - _guideState.targetX) * easeInCubic(t2);
            _guideState.opacity = 1 - t2;
            _guideState.bubbleOpacity = Math.max(0, _guideState.bubbleOpacity * (1 - t2));
            if (t2 >= 1) {
                _guideState.active = false;
                _guideState.phase = 'idle';
                if (_guideState.onComplete) _guideState.onComplete();
            }
            break;

        case 'showing':
            // 气泡渐入动画
            if (_guideState.bubbleOpacity < 1) {
                _guideState.bubbleOpacity = Math.min(1,
                    _guideState.bubbleOpacity + (_guideState.phaseTimer / 150));
            }
            break;

        // idle 阶段无需处理
    }
}
```

### 4.4 advance() — 新增方法

当 battleEvents 触发 first_star_click 时，SceneDispatcher 调用 `dialogueSystem.advance(lines, waitFor)` 推送下一段文字：

```javascript
function advance(lines, waitFor) {
    if (!_guideState.active) return;

    // 如果还在滑入中，直接跳到目标位置
    if (_guideState.phase === 'sliding_in') {
        _guideState.posX = _guideState.targetX;
        _guideState.phase = 'showing';
        _guideState.phaseTimer = 0;
    }

    if (_guideState.phase !== 'showing') return;

    if (lines && lines.length > 0) {
        _guideState.bubbleText = lines[0];
        _guideState.bubbleOpacity = 0;  // 触发气泡弹出动画
        _guideState.phaseTimer = 0;     // 重置计时，气泡渐入从 0 开始
        _guideState.waitForEvent = waitFor || null;
    }

    // 如果这是最后一条 (waitFor === null)，启动滑出计时
    if (!waitFor && _guideState.config.bubbleHoldAfterLast > 0) {
        setTimeout(function() {
            if (_guideState.active && _guideState.phase === 'showing') {
                _guideState.phase = 'sliding_out';
                _guideState.phaseTimer = 0;
            }
        }, _guideState.config.bubbleHoldAfterLast);
    }
}
```

### 4.5 render() 扩展

`guide_anim` 模式下只渲染立绘+气泡，**不绘制背景**（战斗画面由 game.js 的 `renderGame()` 提前绘制，guide_anim 作为叠加层渲染在战斗画面之上）。

```javascript
function render(ctx, screenWidth, screenHeight) {
    // ... 原有 fullscreen 模式渲染逻辑

    // guide_anim 叠加渲染
    if (_guideState.active && _guideState.phase !== 'idle') {
        // 首次 render 时计算坐标（play() 调用时 screenWidth 尚不可知）
        if (_guideState._needsCoordInit) {
            var cfg = _guideState.config;
            _guideState._cachedScreenW = screenWidth;
            _guideState._cachedScreenH = screenHeight;
            _guideState.targetX = Math.floor(screenWidth * cfg.portraitTargetX);
            _guideState.targetY = Math.floor(screenHeight * (1 - cfg.portraitBottomOffset)) - cfg.portraitHeight;
            _guideState.startX = cfg.slideInFrom === 'left' ? -cfg.portraitWidth * 2 : screenWidth + cfg.portraitWidth;
            _guideState.posX = _guideState.startX;
            _guideState.posY = _guideState.targetY;
            _guideState._needsCoordInit = false;
        }

        renderGuideAnim(ctx);
    }

    // ... 原有 overlay 模式渲染逻辑
}
```

`renderGuideAnim` 内部逻辑：

```javascript
function renderGuideAnim(ctx) {
    var gs = _guideState;

    // 1. 获取立绘并渲染
    var image = _deps.getCharacterImage(gs.characterId);
    if (image) {
        renderPortrait(ctx, image, gs.posX, gs.posY,
            gs.config.portraitWidth, gs.config.portraitHeight, gs.opacity);
    }

    // 2. 渲染气泡
    var bubbleX = gs.posX + gs.config.portraitWidth + gs.config.bubbleOffsetX;
    var bubbleY = gs.posY + gs.config.bubbleOffsetY;
    renderBubble(ctx, bubbleX, bubbleY, gs.bubbleText, gs.bubbleOpacity, gs.config.bubbleMaxWidth);
}
```

## 五、渲染实现

### 5.1 布局

```
┌─────────────────────────────────────┐
│                                     │
│          [战斗画面]                 │
│                                     │
│          ┌────────────────┐         │
│          │ 来，先尝试点击  │         │
│          │ 一下灵光吧~    │         │  ← 气泡 (纯 Canvas 绘制)
│          └───┬────────────┘         │
│              ▼                      │
│      ┌──────┐                       │
│      │ 玉蝉 │                       │  ← 立绘 (从图片资源加载)
│      │  仙  │                       │
│      │ 立绘 │                       │
│      └──────┘                       │
└─────────────────────────────────────┘
```

### 5.2 气泡渲染函数

```javascript
function renderBubble(ctx, x, y, text, opacity, maxWidth) {
    if (opacity <= 0 || !text) return;
    ctx.save();
    ctx.globalAlpha = opacity;

    var padding = 12;
    var lineHeight = 18;
    var lines = wrapText(ctx, text, maxWidth - padding * 2, '14px sans-serif');
    var bw = maxWidth;
    var bh = lines.length * lineHeight + padding * 2;
    var bx = x;
    var by = y - bh;

    // 气泡背景
    ctx.fillStyle = 'rgba(255, 255, 255, 0.92)';
    ctx.strokeStyle = 'rgba(180, 160, 120, 0.6)';
    ctx.lineWidth = 1;
    roundRect(ctx, bx, by, bw, bh, 10, true, true);

    // 三角尖 (指向左下方)
    ctx.beginPath();
    ctx.moveTo(bx + 20, by + bh);
    ctx.lineTo(bx + 30, by + bh + 8);
    ctx.lineTo(bx + 40, by + bh);
    ctx.fill();

    // 文字
    ctx.fillStyle = '#333';
    ctx.textBaseline = 'top';
    for (var i = 0; i < lines.length; i++) {
        ctx.fillText(lines[i], bx + padding, by + padding + i * lineHeight);
    }
    ctx.restore();
}
```

### 5.3 立绘渲染函数

```javascript
function renderPortrait(ctx, image, x, y, w, h, opacity) {
    if (!image || opacity <= 0) return;
    ctx.save();
    ctx.globalAlpha = opacity;
    ctx.shadowColor = 'rgba(0, 0, 0, 0.25)';
    ctx.shadowBlur = 6;
    ctx.shadowOffsetX = 2;
    ctx.shadowOffsetY = 2;
    ctx.drawImage(image, x, y, w, h);
    ctx.restore();
}
```

## 六、SceneDispatcher 适配

SceneDispatcher 的 `registerBattleTriggers` 需要适配 `mode: 'guide_anim'`：

```javascript
function registerBattleTriggers(inBattleConfig) {
    if (inBattleConfig.mode === 'guide_anim') {
        inBattleConfig.triggers.forEach(function(trigger) {
            switch (trigger.at) {
                case 'battle_start':
                    setTimeout(function() {
                        dialogueSystem.play({
                            mode: 'guide_anim',
                            guideAnim: inBattleConfig.guideAnim,
                            lines: trigger.lines,
                            waitFor: trigger.waitFor,
                        });
                    }, trigger.delayMs);
                    break;

                case 'first_star_click':
                    // 注册首次点击回调
                    getBattleEvents().onFirstStarClick(function() {
                        dialogueSystem.advance(trigger.lines, trigger.waitFor);
                    });
                    break;
            }
        });
    }
    // ... 其他 mode (overlay 等)
}
```

## 十一、风险与注意事项

| 风险 | 处理 |
|------|------|
| 立绘加载时序 | `getCharacterImage` 应在模块初始化时预加载。如果未加载完成则 guide_anim 降级为无立绘模式（仅显示气泡） |
| 玩家极快点击灵光（滑入未完成） | `advance()` 检测到 `sliding_in` 时直接跳到 targetX 并切换到 showing，跳过剩余滑入动画 |
| 战斗失败重试 | SceneDispatcher 在 onBattleEnd('lose') 时销毁引导状态。重试时触发新的 `battle_start` trigger，DialogueSystem 重新 play guide_anim |
| 立绘比例适配 | `portraitTargetX` 和 `portraitBottomOffset` 使用屏幕比例，`portraitWidth/Height` 可设屏幕比例或固定值，建议用比例 |
| 气泡遮挡灵光操作区 | 气泡在左下角，灵光通常分布在屏幕中部和右下区域。确认 guideAnim 的 X/Y 偏移不进入灵光密集区 |
| `_needsCoordInit` 时序 | play() 和首次 render() 之间可能存在多帧延迟，但 `sliding_in` 从 `posX = startX`（屏幕外）开始，不会在画面中闪烁 |
