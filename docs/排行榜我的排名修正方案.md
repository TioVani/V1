## 方案

### 需要改动

**1. 修复"净化数"数据源**

`MenuRenderer.js:687` 中 `total_kills` tab 读取 `getMonstersKilled()`，其 deps 指向 game.js 全局变量 `monstersKilled`（始终为 0）。

改为读取 TaskSystem 的累计统计 `saveData.taskProgress.stats.monstersKilled`，该值跨局累积且持久化。

或者将 MenuRenderer deps 中的 `getMonstersKilled` 改为 wrapper：
```
getMonstersKilled: function() { return saveData.taskProgress.stats.monstersKilled; }
```

**2. 确认"最高分"和"赛季分"无需改动**

- `bestScore` 链路完整（StorageSystem → localStorage），普通/Boss 模式结算正常写入
- `seasonBestScore` 链路完整（GameLifecycleSystem → GameDataStore）
- 之前在方案文档中描述的"bestScore 从未被赋值"为错误结论，`StorageSystem.saveBestScore()` 在 cleanup 中已调用

### 不改动点

- 无尽之塔分数不入排行榜（独立体系，无对应 tab）
- 关卡模式分数不入排行榜
- 占位榜单数据、特效对齐逻辑均不变
- `bestScore` 持久化链路已正确，无需改动

## 改动文件

- `game.js` L1912：MenuRenderer deps 中 `getMonstersKilled` 改为读取 TaskSystem 累计统计
