# 联连技机制与系统脉络

> 覆盖 Combo（连击）、LinkChain（联连）、RhythmSkill（节奏技）三大子系统及其交互

---

## 一、系统全景

项目中的"联连技"体系由三个相互关联的子系统构成：

```
                    连续点击 (每次攻击)
                         │
                         ▼
              ┌──────────────────┐
              │   ComboSystem    │  ← 连击计数 → 灵光加速 + 伤害倍率
              │   连击系统       │
              └──────┬───────────┘
                     │ comboCount 影响 灵光生成速度
                     │ 并为联连/节奏技提供 comboMultiplier
                     ▼
         ┌───────────────────────┐
         │  充能条 (0 → 200)     │  ← 由蓄力/拖拽/联连划链等行为充能
         │  LinkChainSystem      │
         │                       │
         │  100: 联连技窗口      │  ← 划链匹配灵光 → 联连技/强化联连技
         │  200: 节奏技窗口      │  ← 缩圈点击 → 节拍技
         └───────────────────────┘
```

**三个子系统是"串联升级"关系**：连击系统提供基础层加速和倍率 → 充能达到100触发联连技 → 充能达到200触发节奏技。

## 二、ComboSystem — 连击系统（基础层）

### 2.1 机制

每次点击灵光攻击怪物，连击计数 +1。连击数持续累积，直到超时中断。

### 2.2 效果

| 效果 | 公式/规则 |
|------|----------|
| **伤害乘区** | `伤害 × (1 + comboCount × 0.1)`，15连后收益减半 |
| **灵光加速** | `基础间隔 × (1 - speedBonus)^level`，最多6层加速 |
| **分数加成** | `comboLevel × scoreBonus × (1 + 被动技能加成)` |
| **连击星星** | 连击≥5触发，5秒内每200ms自动攻击一次 |
| **显示提示** | 连击≥5，每隔5层显示"🔥 N COMBO!" |

### 2.3 关键数值

| 参数 | 默认值 | 来源 |
|------|--------|------|
| 连击超时 | 1000ms（角色可定制） | `ComboSystem.js` / 角色配置 |
| 每层倍率 | 0.1 | `CombatSpec.js` → `COMBO.MULTIPLIER` |
| 速度加成层数上限 | 6层 | `ComboSystem.js` |
| 连击星持续 | 5000ms | `CombatSpec.js` |
| 连击星攻击间隔 | 200ms | `CombatSpec.js` |

### 2.4 角色定制

每个角色有4个combo属性：

```
comboThreshold   → 每N连触发一层加成（如 LR 青铜鼎灵 = 2 连一层）
comboSpeedBonus  → 每层灵光间隔缩减比例（如 0.15 = 缩减 15%）
comboScoreBonus  → 每层分数加成
comboTimeout     → 自定义超时时间
```

被动技能 `skill_combo_master`（连灵精通）额外提供 +0.5 的 comboBonus 乘区。

## 三、充能条 — 连接 Combo 与 LinkChain 的桥梁

### 3.1 充能来源

所有高级操作都会为充能条累积进度：

| 行为 | 充能量 |
|------|--------|
| 蓄力吸收灵光 | +5 |
| 拖拽聚合灵光 | +5 |
| 蓄力轻蓄阶段 | +8 |
| 蓄力中蓄阶段 | +12 |
| 蓄力轻蓄释放 | +15 |
| 蓄力中蓄释放 | +25 |
| 蓄力满蓄释放 | +40 |
| 拖拽技释放 | +40 |
| 联连每划一颗 | +5 |

### 3.2 充能条双阶段机制

```
  0 ───────────────── 100 ───────────────── 200
  金色区域              金 + 青双色区域
  ↑ 第一阶段             ↑ 第二阶段
  目标: 联连技           目标: 节奏技
```

**充能规则：**
- 联连流程中（revealing/swiping/judging）：不充能
- 节奏灵光在场时：不充能
- 两个窗口各只出现一次，超时后关闭

### 3.3 窗口生命周期

```
IDLE (0–99)
  │  充能累积
  ▼
100触发 → 第一次联连窗口 (ready)
  │  触发灵光出现，2000ms等待玩家触摸
  ├── 触摸 → 消耗100，进入联连流程
  └── 超时 → 恢复idle，继续充能
  │
150触发 → 第二次联连窗口（最后机会）
  │  同上
  ├── 触摸 → 消耗100，进入联连流程
  └── 超时 → ready_closed，窗口永久关闭，继续充能
  │
200触发 → 节奏技窗口 (rhythm_ready)
  │  清理触发灵光 → RhythmSkillSystem接手
  └── 结算后充能归零
```

## 四、LinkChainSystem — 联连技（第一阶段，charge=100）

### 4.1 解锁条件

角色等级 ≥ 20（或教程完成）

### 4.2 状态机

```
idle → ready → revealing → waiting → swiping → judging → idle
```

| 阶段 | 行为 | 时长 |
|------|------|------|
| **ready** | 随机选一颗灵光作为"触发灵光"，跳动+GC发光等待触摸 | 2000ms超时 |
| **revealing** | 逐颗揭示灵光（发光100ms → 连线动画200ms → 下一颗），同时可滑动 | 与灵光数量有关 |
| **waiting** | 揭示完毕，等待玩家开始划链 | 2000ms超时 |
| **swiping** | 玩家按序划链，命中灵光依次匹配 | 全部划完或停指500ms |
| **judging** | 闪烁判定（成功/失败） | 1000ms |

### 4.3 联连技倍率表

| 匹配数 | 名称 | 倍率 |
|--------|------|------|
| 3颗 | 联连技 | ×3.0 |
| 4颗 | 强化联连技 | ×4.5 |
| 5颗 | 强化联连技 | ×6.0 |
| 6颗 | 强化联连技 | ×8.0 |
| 7颗 | 强化联连技 | ×12.0 |

### 4.4 交互流程

```
1. 充能达到100 → 触发灵光出现（随机选一颗场上灵光，标记 _linking）
2. 玩家触摸触发灵光 → 消耗100充能，进入联连窗口
3. 屏幕变慢（50%时间缩放），随机选 2~6 颗额外灵光标记 _linking
4. 触发灵光作为第1颗，其余按序逐颗揭示
5. 玩家手指滑动，碰触灵光依次匹配
   - 每划一颗 → 发射一颗流星到随机怪物，+5分，+5充能
6. 全部划完或松手 → 进入判定闪烁
7. 成功 → 消耗所有联连灵光，按倍率表对全屏怪物造成伤害
   失败 → 灵光恢复正常生命周期
```

### 4.5 伤害公式

```
总伤害 = Σ(对每只怪: baseAtk × multiplier - shield)
得分 = 30（基础）+ (matchedCount - 3) × 10（强化加成）
```

## 五、RhythmSkillSystem — 节奏技（第二阶段，charge=200）

### 5.1 机制

充能达到200时，在屏幕中央偏下生成一颗节奏灵光。玩家点击激活后，一个缩圈不断缩小，玩家需在最佳时机点击。

```
待激活 → 已激活 → 缩圈循环 (Perfect/Great → 计数+1 → 重置) ... → Miss → 结算
```

### 5.2 缩圈时长递进表

| 连击数 | 缩圈时长 | 特征 |
|--------|---------|------|
| 1–8连 | 1000ms | 固定慢速建立手感 |
| 9–14连 | 800ms | |
| 15–18连 | 650ms | |
| 19–21连 | 520ms | |
| 22–23连 | 420ms | 第22连开始引入随机变速 |
| 24–25连 | 340ms | |
| 26–27连 | 275ms | |
| 28–29连 | 225ms | |
| 30–31连 | 190ms | |
| 32+连 | 165ms | 极限反应 |

第22连开始随机变速模式（35%快缩 / 30%匀速 / 20%忽快忽慢 / 15%急缩）。

### 5.3 判定窗口

- **Perfect**：缩圈完成时刻 ± (缩圈时长 × 10%)
- **Great**：缩圈完成时刻 ± (缩圈时长 × 40%)
- **Miss**：超出 Great 窗口 → 结算

### 5.4 节拍技结算表

| 成功次数 | 名称 | 倍率 | 体力恢复 | 破盾 | 震屏 | 加分 |
|---------|------|------|---------|------|------|------|
| 1–3 | 节奏微震 | ×2.5 | 8% | - | 4 | 10 |
| 4–6 | 节拍技 | ×3.5 | 14% | - | 5 | 20 |
| 7–8 | 强化节拍技 | ×5.0 | 20% | ✓ | 7 | 32 |
| 9–11 | 完美节拍技 | ×7.0 | 28% | ✓ | 9 | 46 |
| 12–14 | 高级节拍技 | ×9.5 | 36% | ✓ | 11 | 62 |
| 15–17 | 极限节拍技 | ×12.5 | 46% | ✓ | 13 | 80 |
| 18–20 | 神之节拍技 | ×16.0 | 56% | ✓ | 15 | 100 |
| 21–23 | 超神节拍技 | ×20.0 | 66% | ✓ | 17 | 125 |
| 24–26 | 传说节拍技 | ×24.0 | 76% | ✓ | 19 | 150 |
| 27–29 | 神话节拍技 | ×28.0 | 86% | ✓ | 21 | 180 |
| 30–31 | 创世节拍技 | ×32.0 | 95% | ✓ | 23 | 210 |
| 32+ | 终极节拍技 | ×40.0 | 100% | ✓ | 28 | 250 |

### 5.5 伤害公式

```
总伤害 = baseAtk × multiplier（全屏AOE）
体力恢复 = stamina%（直接恢复 SaturationState）
每次成功点击额外 +5 分
```

## 六、输入路由 — TouchGestureSystem 触摸优先级

```
主线触摸处理顺序:
  1. rhythmSkillSystem.handleTouch(touch)      ← 节奏灵光在场时独占
  2. linkChainSystem.handleTriggerTouch(touch)  ← 触发灵光在场时
  3. touchGestureSystem.handleGestureStart()    ← 通用手势分发
       ├── D4_SWIPE:  联连划链模式
       ├── D2_MONITOR: 监控长按 → 蓄力
       ├── D3_DRAG:   拖拽聚合
       └── D1_CLICK:  普通点击攻击
```

## 七、灵光保护标记体系

多个系统同时操作灵光时，通过 `_xxx` 标记互斥：

| 标记 | 设置方 | 含义 |
|------|--------|------|
| `_linking` | LinkChainSystem | 联连窗口中的灵光，StarSystem不清理 |
| `_dragging` | DragSystem | 被拖拽吸附的灵光，联连系统跳过 |
| `_charging` | ChargeSystem | 被蓄力锁定的灵光 |
| `_rhythm` | RhythmSkillSystem | 节奏灵光标记 |

## 八、与其他系统的交互矩阵

| 关联系统 | 关系 |
|---------|------|
| **SaturationState（体力条）** | 联连技成功恢复体力；节奏技按等级恢复体力 |
| **ChargeSystem（蓄力）** | 各种蓄力操作充能 +5/+8/+12/+15/+25/+40 |
| **DragSystem（拖拽）** | 每吸附+5充能，拖拽技释放+40充能 |
| **NormalBattleAdapter** | 战斗入口统一管理充能调用、伤害计算、元素联连 |
| **Score** | 联连技30分起+强化加值；节奏技每点击+5分+结算加分 |
| **AnimationSystem** | 联连流星复用通用流星动画 |
| **StarSystem** | 通过 `_linking` 标记让联连灵光免于正常生命周期 |

## 十、联连技完整操作流水线

```
1. 打怪 → ComboSystem 记录连击 → 灵光加速 + 伤害放大
2. 蓄力/拖拽操作 → 充能条累积 (0→100→200)
3. 充能到100 → 触发灵光 → 触摸 → 进入联连窗口
4. 联连窗口内：逐颗揭示灵光 → 按序划链 → 3~7颗匹配
5. 判定成功 → 按倍率表释放联连技/强化联连技（×3.0 ~ ×12.0）
6. 充能到200 → 触发节奏技窗口 → 缩圈循环
7. 缩圈内 Perfect/Great → 计数累加，缩圈重置（不限次数）
8. Miss → 按成功次数查结算表释放节拍技（×2.5 ~ ×40.0）
9. 结算后充能归零 → 回到步骤1
```
